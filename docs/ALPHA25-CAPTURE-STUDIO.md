# Legion Control alpha.25 — Capture Studio

**Новый самостоятельный функционал:** ручная запись экрана Android 13+ в MP4 (H.264) для любой игры или приложения. Это не сбор игровой телеметрии, не замер FPS, не Game Toolbox и не Audio Lab.

## Возможности

1. **Одноразовое согласие Android на каждый сеанс** через системный MediaProjection chooser. Если пользователь отменяет диалог, запись и создание файла не происходят. Сеанс не может быть повторно запущен старым разрешением на Android 14+.
2. **Видео MP4 без звука**, с настройкой длинной стороны кадра 1280/1920 px, запрашиваемой частоты 30/60 кадров/с, битрейта 4/8/12 Мбит/с, автостопом 1/5/15 минут. Сохраняется пропорция дисплея, размеры чётные и не увеличиваются сверх исходных. Выбранные FPS/битрейт — параметры запроса кодеку, а не измерения реальной игры.
3. **Foreground-сервис записи** с видимым уведомлением и кнопкой **«Остановить»**. Программная остановка при истечении выбранного лимита или отказе системного MediaProjection. Никакого автоматического запуска при старте устройства.
4. **Безопасное сохранение в MediaStore**: клип создаётся в `Movies/LegionControl/` как незавершённый `IS_PENDING=1`, публикуется только после успешной остановки MediaRecorder. При сбое кодирования, слишком короткой записи или ошибке создания файл удаляется вместо публикации повреждённого MP4.
5. **Моя библиотека клипов**: локальная выборка только видеозаписей, владельцем которых является пакет Legion Control, в его папке. Просмотр через системный видеоплеер, отправка через Android Sharesheet, удаление *одного выбранного видео* только после явного подтверждения. Никакого `READ_MEDIA_VIDEO`, `MANAGE_EXTERNAL_STORAGE` или чтения чужих файлов.
6. **Переход в выбранную игру из Game Toolbox** — дополнительная кнопка после запуска записи. Без вторичного оверлея или самостоятельных автоматических системных переключений.

## Запуск

1. Обновите подписанную alpha.24 без удаления приложения.
2. Откройте **CAPTURE STUDIO · запись экрана и клипы MP4** в главном меню Legion Control.
3. Выберите разрешение, запрашиваемый FPS/битрейт и максимальную длительность. Надёжнее начинать с 1280/30 FPS/4 Мбит/с.
4. Нажмите **НАЧАТЬ ЗАПИСЬ ЭКРАНА**, выберите доступный Android режим захвата (полный экран или одно приложение в зависимости от версии), подтвердите разрешение.
5. Переключитесь в игру. Запись активна только после успешного запуска сервиса/кодека. **Остановите через уведомление** или кнопку **ОСТАНОВИТЬ ЗАПИСЬ** в приложении. Для следующего сеанса требуется новое разрешение.
6. Вернитесь в Capture Studio → **ОТКРЫТЬ БИБЛИОТЕКУ КЛИПОВ** → просмотр, отправка или подтверждённое удаление.

## Что важно

- **Нет звука**: встроенный аудиозахват и микрофон не реализованы. Не запрашивается `RECORD_AUDIO`.
- Secure/DRM-экраны, отдельные игры и административные ограничения могут показывать чёрный кадр либо запрещать запись. Приложение не обходит защиту системы.
- Android 14+ запрещает повторное использование токена захвата; приложение запрашивает новый каждый раз. Android 15+ не допускает запуск этого типа сервиса из `BOOT_COMPLETED`; подобного ресивера нет.
- Ориентация или размер захватываемой области могут измениться во время записи, особенно в режиме захвата отдельного приложения. Текущая версия использует фиксированный размер кодируемого MP4; возможны поля, обрезание или необходимость нового сеанса после поворота.
- Некоторые устройства не поддерживают выбранный формат H.264/FPS/битрейт. В таком случае запись может не начаться, а неполный файл удалится.
- Захват экрана может записать личные уведомления и сообщения. Пользователь сам включает и завершает запись.
- Экранный захват создаёт нагрузку на кодек, расходует батарею и может влиять на игру; улучшения FPS не заявляются.
- Управление записью через уведомление требует корректной работы foreground-сервиса, а OEM может ограничивать его. Устройство Lenovo Legion Y70/Motorola требует отдельной физической проверки.

## Совместимость, безопасность и проверка

- Версия `0.1.0-alpha.25`, `versionCode=25`. Прежние `dev.lolokeksu.legioncontrol`, PKCS12 signer, Rust JNI, все таблицы SQLite v12 и предыдущие данные неизменны.
- **Новое только обычное разрешение foreground-сервиса** `FOREGROUND_SERVICE_MEDIA_PROJECTION`, плюс новое системное согласие при каждом захвате. Не требуются Root, Shizuku, Accessibility, геолокация, микрофон, доступ ко всем пакетам или всем видео.
- Автоматическая проверка: `CaptureConfigTest` (Kotlin/JVM), `scripts/check_alpha25_capture_studio.py` (статический контролируемый контракт), все прежние SQLite, Kotlin, Rust, Android/lint и закреплённая release-подпись.
- **Отдельная физическая приёмка**: запись 30–60 секунд и воспроизведение MP4 на Lenovo ROM, отказ в разрешении без файла, успешная публикация и галерея, остановка из уведомления, автолимит, очистка неполной записи, фон/ориентация, разовый токен, системные protected surfaces, перенос alpha.24→25 с сохранённой SQLite. CI не доказывает эти физические сценарии.
