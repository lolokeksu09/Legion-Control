# Legion Control — карта функциональности и навигации

## Решение
Сохраняем пять существующих вкладок Navigation Component и действующие экраны. Первичная навигация определяется задачей пользователя, а не внутренним названием лаборатории.

| Вкладка | Основная задача | Функции |
| --- | --- | --- |
| Главная | Понять состояние устройства и быстро начать работу | Сводка батареи/частоты экрана, мои игры, быстрые действия записи и игровой панели, последняя сессия |
| Игры | Найти игру и управлять игровыми функциями | Game Hub, карточка игры, Application Center, Game Session, Game Toolbox, Smart Profiles |
| Инструменты | Запустить ручную проверку или запись | Поиск по инструментам; Capture Studio, Audio Lab, Display Patterns, Haptic Lab, Gamepad Live, Gaming Lab, Hardware Lab, Compatibility Lab, диагностика Kotlin+Rust, Connectivity Observatory, Experiment Lab |
| История | Найти результаты и сравнить прогоны | Игровые сессии, MP4, Session Signals, Session Baselines, Session Incidents, Experiments, измерения устройства, история приложений, последние сессии |
| Настройки | Управлять конфигурацией и разрешениями | Настройки Game Toolbox/Smart Profiles, данные Application Center, спецдоступы Android, информация о приложении |

## Основное место функции и контекстные переходы

- **Game Session, Game Toolbox, Smart Profiles:** вкладка «Игры». Быстрые ссылки с «Главной» и настройки внутри соответствующих модулей остаются.
- **Capture Studio:** «Инструменты» для запуска захвата; «История» для просмотра собственных MP4.
- **Gamepad Live, Audio Lab, Haptic Lab, Display Patterns:** инструменты ручной проверки.
- **Gaming Lab, Hardware Lab, Compatibility Lab, диагностика Kotlin+Rust:** инструменты анализа устройства. Исторические измерения доступны также с «Истории».
- **Connectivity Observatory:** сетевые инструменты.
- **Experiment Lab:** инструмент создания сравнения, результаты доступны с «Истории».
- **Application Center:** библиотека во вкладке «Игры»; сохранённые данные/настройки и история доступны через контекстные ссылки.

## Требования и критерии приёмки

- **IA-01:** все существующие модули доступны; все 11 диагностических/медийных инструментов отображаются в каталоге «Инструменты» без дублирования внутри него.
- **IA-02:** поиск фильтрует инструменты и названия групп в текущей вкладке без перезагрузки HubViewModel, а пустой результат объясняется пользователю.
- **IA-03:** главная навигация остаётся из пяти вкладок, поддерживает Android Back; контекстные ссылки открывают прежние действующие Activity/Fragment.
- **IA-04:** идентификатор пакета, SQLite v12, схема разрешений, Rust JNI, сервисы, подпись и релизные workflow не меняются.
- **IA-05:** пустой Game Hub по-прежнему даёт аварийный доступ к отдельным модулям.
- **IA-06:** MainActivity показывает ручное измерение первым, а ссылки на соседние модули — после собственных диагностических функций.
- **IA-07:** Capture Studio показывает кнопки записи до настроек качества и игровых профилей, не меняя согласие MediaProjection и реальную обработку.
- **IA-08:** Gaming Lab, Hardware Lab и Compatibility Lab разделяют проверки на группы (сеть, питание, экран, контроллеры, отчёты); Application Center отделяет библиотеку, карточку приложения, проверки и удаление.
- **IA-09:** вложенные игровые экраны подсвечивают вкладку «Игры», экраны анализа сессий — «История», лаборатории — «Инструменты»; общие подписи вкладок берутся из `HubTab`.
- **IA-10:** Capture Studio показывает «Запись», затем «INSTANT REPLAY» и «Скриншот», затем необязательные настройки кодирования/профилей; все существующие действия сохраняют обработчики.
- **IA-11:** Smart Profiles разделяет редактирование профиля, аналитику, сетевые проверки, громкость, DND, управление экраном и резервные копии; Connectivity Observatory показывает результаты рядом с запуском теста.
- **IA-12:** UI-приёмка на установленном APK: найти «Audio Lab» поиском, открыть его, вернуться жестом Back; открыть Game Session из «Игры»; открыть клип из «Истории»; проверить поиск с нулём совпадений и поворот/повторное открытие экрана.

## Объём изменений этой ветки

Первый срез: реорганизация верхнеуровневого HubPageFragment, тематический каталог с поиском, упорядочение разделов «Игры» и «История»; в legacy MainActivity непосредственные действия по батарее, сеансам и датчикам сгруппированы по задачам, а старые ссылки на другие модули перенесены после диагностики. **Не выполнены в этой ветке:** полная унификация внутренних интерфейсов оставшихся лабораторий, перенос всех Activity на общую структуру экранов, сквозной поиск по подфункциям, перепроектирование «Настроек» в самостоятельный центр конфигурации. Это следующие отдельные изменения, а не скрыто удалённый функционал.

## Проверки
Коммит ветки должен пройти Kotlin/Rust CI и Android 15 emulator smoke. Отдельно требуется проверка на физическом Lenovo Legion Y70: Back, действия по разрешениям, MediaProjection, выбор игры, состояния истории, системные Insets и масштаб шрифта. CI не подтверждает работу оборудования автоматически. Публикация APK не входит в этот PR.
