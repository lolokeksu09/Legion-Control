# Legion Control — Game Sessions / 4PDA

## Назначение и совместимость

Версия 0.1.0-alpha.17 (`versionCode=17`) — универсальная локальная диагностика во время игры или использования выбранного приложения. Не ограничена Wild Rift. Android 13+ (`minSdk=33`), ARM64 и x86_64 (согласно текущей конфигурации Rust/Android). На прошивках со строгой оптимизацией аккумулятора foreground service может быть остановлена. Проверять работу на физических устройствах; успешный CI не доказывает её на каждом OEM.

## Как использовать

1. Откройте Legion Control → GAME SESSION.
2. Выберите установленное приложение из списка (Android Launcher) или укажите точное имя пакета и подпись.
3. По желанию включите TCP-тест `one.one.one.one:443`; по умолчанию он отключён. Интернет также требуется для этой проверки, но не для обычной записи.
4. При необходимости отдельно разрешите уведомления; это помогает видеть статус.
5. Нажмите «НАЧАТЬ ЗАПИСЬ», дождитесь уведомления, затем откройте нужную игру.
6. Вернитесь и остановите запись или нажмите «Остановить» в уведомлении.
7. Просмотрите локальную историю, сравнение, график температуры батареи или экспортируйте CSV/ZIP через Android Documents UI.

Выбор пакета — только метка сессии. Приложение не считывает внутреннюю статистику других программ и не может гарантировать, что выбранная игра была активна всё время. Usage Access относится к существующему отдельному Game Session Tracker и не требуется для новой записи.

## Данные и источники

- `ACTION_BATTERY_CHANGED`: процент и температура аккумулятора (десятые доли °C).
- `BatteryManager`: ток батареи, только при поддержке OEM; не ток зарядного устройства.
- `PowerManager`: Android Thermal Status и энергосбережение; не CPU/GPU термометр.
- `DisplayManager`: объявленная частота экрана; не FPS игры.
- `ConnectivityManager`: тип активной сети и `NET_CAPABILITY_VALIDATED`. VPN может изменить представление транспорта. Это не ping до сервера игры.
- Опционально пять TCP-подключений к Cloudflare `one.one.one.one:443`, не чаще ~120 секунд с дополнительными защитами от сильного нагрева.

Данные остаются в приватной SQLite базе приложения. Нет собственного сервера, аналитического SDK, рекламных запросов, автозагрузки, облачной синхронизации, доступа к геолокации, root, Shizuku, скрытым OEM-командам или глобальному перехвату. Пользователь сам решает, когда экспортировать архив через системный выбор документа. Файлы экспортируются без секретов и персональных идентификаторов сети (IP/SSID), но **названия приложений и временные метки могут быть личными данными** — предупреждайте об этом перед публичной отправкой отчёта.

## Разрешения и Android 14+

- `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` — прежние права диагностики; активный TCP только opt-in.
- `PACKAGE_USAGE_STATS` — прежний необязательный спецдоступ, не требуется для новых сессий.
- `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE` — для явно запускаемой записи при переходе в игру; `specialUse` и объяснение в manifest обязательны для targetSdk 36.
- `POST_NOTIFICATIONS` — отдельно запрашиваемое разрешение Android 13+.
- `queries MAIN/LAUNCHER` — видимые launchable-приложения, без `QUERY_ALL_PACKAGES`.

На Google Play потребуется отдельная проверка политики `specialUse`; публикация на 4PDA её не заменяет.

## Перед публикацией

- Убедиться, что GitHub Actions завершились успешно: Kotlin JVM tests, SQLite v5→v6, Android Debug build/lint, Rust JNI, release signing gate.
- Установить **signed release** с закреплённым сертификатом поверх предыдущего signed release и убедиться в сохранении старой истории. Не ставить Debug APK поверх Release; Android отклонит другую подпись.
- На разных Android/OEM проверить: запрос уведомлений; старт в foreground; реальный переход в любую игру; длительную запись ≥10 минут; сетевой переход Wi-Fi↔LTE; выключенный интернет; остановку из уведомления; экспорт обоих форматов; открытие ZIP.
- Проверить отсутствие самопроизвольного старта записи после перезагрузки и отсутствие лишних сетевых обращений при выключенном TCP-флажке.
- До фактической проверки устройств не заявлять полноценную совместимость, игровой FPS, ping Riot, настройку сенсора или управление системными частотами.

## Версия и лицензирование

Проект сохраняет прежний applicationId `dev.lolokeksu.legioncontrol` и релизный ключ из GitHub Actions Secrets. Ни исходные закрытые ключи, ни релизные APK не добавляются в git. Фактическая публичная alpha.17 доступна только после успешного CI и релизной сборки.
