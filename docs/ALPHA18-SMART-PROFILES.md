# Legion Control · alpha.18 — Smart Profiles & Automation

Android 13+ · ARM64 / x86_64 · Kotlin + Rust · no Root / Shizuku

## Что появилось

**Smart Profiles** — локально сохранённые параметры для любой игры или launchable-приложения: package name, название, температура батареи для предупреждения (30–55 °C), порог низкого заряда (5–80%) и отдельное разрешение TCP-проверки. Приложение не связано с Wild Rift. Пакет может быть указан вручную; автообнаружение использует только публичный Launcher API, не `QUERY_ALL_PACKAGES`.

**Smart Rules** — шесть типов правил: горячая батарея, низкий процент батареи, серьёзный Android Thermal Status, включённое энергосбережение, отсутствие подтверждённого Android интернет-соединения и смена сетевого транспорта. Значения берутся из публичных Android API. Правила проверяются только в **явно запущенной пользователем игровой сессии** и примерно каждые 15 секунд. Изменения правил применяются при следующем запуске. Срабатывания сохраняются в SQLite, а отдельное предупреждающее уведомление отправляется **только если пользователь разрешил уведомления**. Повторное непрерывное событие не вызывает бесконечный поток предупреждений; дополнительно есть cooldown.

**Системные действия** доступны по отдельным нажатиям: громкость мультимедиа; «Не беспокоить» (спецдоступ Notification Policy); яркость 50% и тайм-аут 2 минуты (спецдоступ WRITE_SETTINGS). Для экранных параметров сохраняются предыдущие значения и доступна кнопка ручного восстановления. Ни одно из этих действий **не запускается автоматически при входе в игру**. Некоторые OEM могут отклонять запросы.

**Smart Insights** — сводка по конкретному пакету за 24 часа, 7 и 30 дней: завершённые сессии и их длительность, количество замеров, максимум температуры **батареи**, показания Android Thermal Status и невалидированную сеть. Незавершённые сессии не включаются во время. Не заявляет FPS игры, игровой ping, CPU/GPU температуру или причинно-следственную диагностику лагов.

**Network Quality Lab** — разовый, пользовательский DNS/IPv4/IPv6/TCP connect тест до `one.one.one.one:443` (Cloudflare); включает внешний сетевой запрос **только после нажатия**. Никакие внутренние сервера игры не опрашиваются. Никакого ICMP ping и скрытого захвата трафика.

**JSON backup/restore** — локальный файл с профилями/правилами, экспорт и импорт через Android Documents UI, проверка формата и предельного размера 512 KiB, транзакционная запись, подтверждение перед импортом. Совпадающие профили изменяются, **старые игровые сессии и замеры не удаляются**. История сессий экспортируется отдельно через старый Game Session CSV/ZIP и не включена в JSON.

**Quick Settings Tile** — пользователь сам добавляет плитку Legion Control в редакторе шторки. По нажатию плитка открывает экран Smart Profiles; **тайная фоновая запись не запускается**. Для Android 14+ используется `startActivityAndCollapse(PendingIntent)`.

**Compatibility Engine** — отражает Android API и выданные специальные разрешения отдельно от непроверенных возможностей OEM. Без Root и Shizuku.

## Как пользоваться

1. Откройте Legion Control → **SMART PROFILES**.
2. Выберите установленную игру/приложение; задайте название, температуру и минимальный заряд; при необходимости явно разрешите TCP.
3. Сохраните профиль. Настройте включённость шести правил.
4. Нажмите «Открыть Game Session с этим профилем», затем **«НАЧАТЬ ЗАПИСЬ»** и перейдите в игру. Только это запускает foreground service.
5. Вернитесь и остановите запись из приложения или системного уведомления.
6. Просмотрите предупреждения и статистику, при необходимости сохраните JSON профилей или CSV/ZIP сессий.

Для DND и системных параметров откройте их спецдоступы в Android **отдельными** кнопками. Если доступ не предоставлен, попытка изменения должна завершиться понятным отказом. Изменение яркости переключает автоматическую яркость в ручной режим; используйте восстановление для возврата прежнего режима.

## Данные и безопасность для 4PDA

- `applicationId` прежний: `dev.lolokeksu.legioncontrol`; `versionCode=18`.
- SQLite v6→v7: **только новые** таблицы профилей, правил, событий. Существующая история не стирается.
- Публичные Android API, без root, системных OEM обходов, Shizuku, ACCESS_FINE_LOCATION, QUERY_ALL_PACKAGES или WRITE_SECURE_SETTINGS.
- Разрешения сверх alpha.17: `MODIFY_AUDIO_SETTINGS` (обычное) и спецдоступы `ACCESS_NOTIFICATION_POLICY` и `WRITE_SETTINGS`. Режимы изменяются только вручную.
- Данные остаются локальными; наружу выходят только по добровольной TCP-проверке или через явный пользовательский экспорт. Никаких аналитических SDK/телеметрических серверов.
- Выбор приложения обозначает **метку** сессии; без отдельного специального доступа нельзя гарантировать foreground конкретной игры. Счётчики батареи/OEM могут быть недоступны.

## Обязательные проверки перед публичной выкладкой

1. Зелёный GitHub Actions: real SQLite v6→v7, JUnit, Android `assembleDebug lintDebug`, Rust JNI, release-signing fingerprint.
2. Поверх старого **signed alpha.17** установить подписанный alpha.18 с прежним сертификатом; проверить сохранение SQLite.
3. На физическом Android устройстве проверить добавление/удаление профиля, изменения правил, запись во время игры, получение и отключение уведомлений, остановку из шторки, экранные разрешения, восстановление яркости, подтверждение импорта и JSON round-trip.
4. Проверить поведения offline / на разных OEM и отсутствие самозапуска записи. Без этих проверок нельзя заявлять полноценную совместимость.
