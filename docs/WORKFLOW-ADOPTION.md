# Применение Project Workflow Standard v1.0 к Legion Control

**Основание:** архив пользователя `Project-Workflow-Standard-v1.0(2).zip` (2026-11-21). Он используется как методический шаблон; не как новое разрешение на опасные операции или публикацию приложения.

## Активные документы

- [`AGENTS.md`](../AGENTS.md) — активные инструкции агента: нормативная часть v1.0 с поправленными ссылками и проектным дополнением.
- [`PROJECT.md`](../PROJECT.md) — заполненная карточка Legion Control с подтверждёнными ссылками на код/CI.
- [`TESTING-LEVELS.md`](../TESTING-LEVELS.md) — уровни L1–L5 плюс карта реальных проверок Kotlin/Rust/JNI.
- [`README.md`](../README.md) — существующее техническое описание приложения сохраняется; стандарт не заменяет его.

## Архив стандарта

Полный оригинал без переписывания находится в [`workflow-standard/`](../workflow-standard/README.md): 15 Markdown документов, скрипт проверки и 3 учебных примера, включая шаблоны PLAN, CONTINUATION, AUDIT, VERIFICATION и RELEASE. Эти **образцы не являются активными задачами**. В случае конфликта проектных фактов приоритет у проверенного текущего кода/контракта и применимых внешних инструкций, не у пустой карточки образца.

## Проверка

```bash
python3 workflow-standard/tools/check_standard.py workflow-standard
python3 scripts/check_workflow_integration.py
```

Первая проверка — неизменность нормативного комплекта (8 структурных проверок). Вторая — наличие активных документов, относительные ссылки и сохранность действующих команд CI. Обе — **L1**, не тест Rust backend и не доказательство работы на устройстве.

Android CI дополнен двумя быстрыми шагами до запуска долгих сборок. Существующие `scripts/check_backend.py`, `scripts/build-native.sh`, `gradle assembleDebug lintDebug`, `scripts/verify_apk.py` и upload APK сохранены.

## Режим работы

- **Light:** локальные правки и документация, краткие записи и целевые проверки по риску.
- **Full:** сложные зависимые задачи, один реестр требований с REQ-ID, проверки и остаток; рабочая копия шаблона при необходимости.
- **Выпуск:** отдельное решение о публикации. CI PASS и созданный Debug APK не означают release и не подтверждают установленную версию.
