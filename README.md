**Актуальный аудит (26.11.2026):** [реестр LC-01–13 и Roadmap Beta](docs/AUDIT-2026-11-26.md) · [Stability & Safety](docs/STABILITY-SAFETY-2026-11-26.md). Карта разделов и всех основных функций: [информационная архитектура Legion Control](docs/FEATURE-INFORMATION-ARCHITECTURE.md). Навигация сохраняет 5 вкладок: Главная / Игры / Инструменты / История / Настройки.

Самостоятельное Android-приложение для Lenovo Legion Y70 и других Android 13+ устройств. Сочетает ручные проверки, системные инструменты и Game Toolbox поверх игр — без Root/Shizuku.

## Стек
- **Kotlin/Android:** получение данных через публичные Android API, разрешения и жизненный цикл.
- **Rust:** проверка показаний и расчёт изменений батареи в ограниченном 64-сэмпловом буфере.
- **JNI:** связь между Kotlin и Rust для Android ARM64.

Ручные замеры и локальная история не отправляются на сервер. Некоторые инструменты **по отдельному нажатию пользователя** изменяют глобальные громкость, DND и яркость через публичные Android API и штатные спецдоступы. Root/Shizuku не используются. Исходный `Lenovo-Y70` оставлен без изменений.

См. `rust-core/`, `android-core/`, `docs/BACKEND.md`. Следующие шаги: Rust unit tests в CI, Android JNI сборка, затем легковесный Kotlin-интерфейс. Никаких заявлений об улучшении FPS, сенсорного отклика или Bypass.

Последняя опубликованная версия: [Alpha 49](https://github.com/lolokeksu09/Legion-Control/releases/tag/v0.1.0-alpha.49). Alpha 54 — [интеграционный кандидат](docs/ALPHA54-INTEGRATION.md) с изменениями Alpha 50–53; подписанный релиз пока не выпущен.

## v0.1.0-alpha.25 — Capture Studio (реальная запись экрана)

В главном меню появился **Capture Studio**: после отдельного согласия Android через MediaProjection пользователь может записать экран в MP4 (MediaRecorder H.264, **без звука**), ограничить разрешение 1280/1920 px по длинной стороне, запрашиваемую частоту 30/60 FPS, битрейт 4/8/12 Мбит/с и длительность 1/5/15 минут. Запись выполняется в явно запущенном foreground-сервисе, останавливается из системного уведомления, вручную или по лимиту. Нет фонового автозапуска, обходов DRM, доступа к другим приложениям или невидимой записи.

MP4 создаются только в `Movies/LegionControl/` через MediaStore: до успешного завершения файл скрыт (`IS_PENDING=1`), при ошибке кодирования удаляется. **Библиотека собственных клипов** позволяет открыть видео системным проигрывателем, поделиться через системное меню или удалить выбранный файл после подтверждения. Все прежние данные SQLite v12, Rust JNI, идентификатор пакета и сертификат сохранены. Добавлен только `FOREGROUND_SERVICE_MEDIA_PROJECTION`; новое согласие Android запрашивается для **каждого** сеанса, без Root/Shizuku/микрофона.

Важные ограничения: 30/60 — запрос кодеку, не фактический FPS игры; некоторые защищённые окна нельзя записать; OEM/Android могут отказаться от захвата; изменение ориентации может вызвать поля/обрезание фиксированного видеокадра. Работу на Lenovo Motorola ROM нужно проверять отдельно после установки.

## v0.1.0-alpha.24 — Game Toolbox (не диагностический)

Новый **Game Toolbox** — пользовательский плавающий инструмент поверх любой игры/приложения. Пользователь вручную разрешает показ поверх других окон, запускает панель и по необходимости выбирает установленную игру через стандартный Launcher API. Компактную кнопку **LC** можно перемещать, раскрывать и сворачивать; расположение, размер и прозрачность хранятся локально.

В панели: реальная регулировка громкости мультимедиа, включение/выключение «Не беспокоить» (со спецдоступом Android), яркость 50%/80% и восстановление исходной яркости (спецдоступ WRITE_SETTINGS), запуск заранее выбранной игры, переход в настройки и полное выключение. Панель работает как явно запущенный foreground service с кнопкой **«Остановить»** в уведомлении; без скрытого старта, без записи ввода или доступа к экрану игры.

**Важно:** спецдоступ SYSTEM_ALERT_WINDOW предоставляется отдельно в Android; он может быть заблокирован OEM/защищённой игрой. Громкость, DND и яркость изменяются только по нажатию, автоматически после закрытия панели не восстанавливаются. Доступен ручной возврат яркости; режим DND выключают вручную. Никаких обещаний повышения FPS/CPU/GPU, Bypass, Touch Boost. Нет Root/Shizuku, новых сетевых запросов и изменения SQLite v12.

[План и критерии](docs/ALPHA24-GAME-TOOLBOX-PLAN.md) · [Руководство](docs/ALPHA24-GAME-TOOLBOX.md).

## v0.1.0-alpha.3 — сеансы Rust и реальные данные питания

- **Нативный сеанс:** Rust хранит до 64 замеров в оперативной памяти, вычисляет длительность между первым и последним удержанным замером (через Android `elapsedRealtime`) и по подтверждению пользователя очищает историю. Сброс не меняет параметры телефона. После него нужен новый запрос измерения.
- **Android Power API:** статус и источник зарядки, напряжение батареи, ток `BATTERY_PROPERTY_CURRENT_NOW` (если доступен) и энергосбережение. Ток показывается как сырая величина со знаком, без ложного утверждения об эффективности, Bypass или состоянии здоровья батареи.
- **Экспорт:** кнопка «Поделиться отчётом» отправляет пользователем выбранному приложению последний успешный снимок через системный Android Sharesheet. Нет автоматической отправки и разрешения на доступ к памяти.
- **Подпись:** `versionCode=3`. Постоянный сертификат SHA-256 и четыре GitHub Secrets не менялись; `assembleRelease` по-прежнему запрещён без релизного ключа. Документ: [RELEASE-SIGNING](docs/RELEASE-SIGNING.md).

Тестирование: Rust unit tests, статическая проверка Kotlin JNI, Android CI debug-build. Проверка поведения на физическом Y70 выполняется отдельно после установки.

## v0.1.0-alpha.4 — сохраняемая диагностика

- **Локальная SQLite история:** отдельные сеансы и все успешно записанные измерения сохраняются в приватной базе, остаются после перезапуска приложения. Никаких сетевых запросов, разрешений на хранилище или автоудаления истории.
- **Rust:** сохраняет действующее окно из не более 64 измерений исключительно в RAM и вычисляет статистику/длительность; при перезапуске процесса начинается новый native-сеанс. SQLite и Rust выполняют разные задачи.
- **Экспорт CSV:** выбор имени и места хранения через штатный Android Documents UI (`ACTION_CREATE_DOCUMENT`), потоковая UTF-8 выгрузка без записи публичного файла до согласия пользователя. Содержит время, процент и температуру батареи, ток/напряжение, режим дисплея и признаки зарядки.
- **Проверка датчиков:** обнаружение акселерометра, гироскопа, освещённости, приближения, окружающей температуры через публичный `SensorManager`. Отсутствие видимого датчика не означает аппаратный дефект; данные CPU/GPU не выдаются за публичные датчики.
- **Исправление русского языка:** `2 измерения`, `5 измерений`, `21 измерение`. JVM регрессии проверяют формат CSV и склонение.
- **Релиз:** `versionCode=4`, прежний PKCS12 SHA-256 остаётся закреплённым. Подписанный APK автоматически собирается только при trusted push на `main` (после merge) либо вручную. Debug APK **нельзя** ставить поверх релизного без удаления приложения и потери локальных данных.

[Контракт хранения, экспорта и проверки на Lenovo Y70](docs/HISTORY.md). После получения APK проверь реальное сохранение между запусками, экспорт и датчики на устройстве.

## v0.1.0-alpha.14 — Gaming Lab: 10 ручных диагностик

9. Session Comparison: фактические изменения заряда и температуры за два сохранённых сеанса в существующей SQLite v5.
10. System Health: RAM, свободное хранилище, PSS собственного процесса, режим дисплея.

## v0.1.0-alpha.15 — Hardware Lab (6 новых модулей)

По кнопке **HARDWARE LAB** внутри Gaming Lab открывается дополнительный экран с шестью настоящими функциями без Root/Shizuku:

1. **Local Route Inspector:** активный сетевой интерфейс Android, локальные IP, DNS и адреса шлюзов, состояние Private DNS через ConnectivityManager/LinkProperties. Данные могут принадлежать VPN, не обязательно Wi-Fi-роутеру; не сканируются соседи и не требуется геолокация.
2. **Network Events (30 с):** по нажатию регистрируется штатный NetworkCallback на 30 секунд; фиксируются события подключения, потери сети, валидации и изменений маршрута. До 64 событий, дубликаты ограничены. Это не ICMP ping, не сниффер трафика и не мониторинг игры.
3. **Storage Lab:** в приватном кэше создаётся временный файл 8 МиБ, измеряется последовательная запись с fsync и чтение, а данные проверяются SHA-256. Файл удаляется даже при ошибке. Чтение может ускоряться page cache Android — не официальный бенчмарк накопителя, результаты от условий зависят.
4. **Motion Stability (5 с):** реальные SensorEvent акселерометра и гироскопа, приближённый наклон от +Z, разброс ускорения и RMS угловой скорости. Отсутствующие/неверные значения не подменяются нулями. Не компас, не калибровка тача или акселерометра.
5. **Display Patterns:** ручной полноэкранный показ чёрного/белого/красного/зелёного/синего/серого. Нажатие переключает цвет, «Назад» закрывает проверку; системная яркость/частота дисплея не меняются. Дефектные пиксели оценивает сам пользователь, автоматической «диагностики пикселей» нет.
6. **Codec Inspector:** Android MediaCodecList показывает наличие доступных видеодекодеров AVC, HEVC, VP9, AV1 и отметку аппаратного ускорения. Наличие декодера не подтверждает возможность воспроизведения конкретного файла или производительность Wild Rift.

Доступна ручная отправка последнего текстового отчёта через системное меню. Все тесты явные и локальные; обработчики событий отменяются при сворачивании, запись/чтение Storage Lab работает на отдельном worker. **Не добавлены** дополнительные разрешения, новые таблицы SQLite или изменения Rust JNI. Все прежние функции alpha.14 сохранены, база остаётся SQLite v5; установка поверх предыдущей версии должна сохранять историю. Проверки GitHub Actions включают JVM-математику, контрактные тесты API/разрешений и прежнюю полную Android/Rust/пиннинг подписи цепочку. Физические датчики, сетевые callbacks и визуальную проверку дисплея нужно проверить на Lenovo Y70 отдельно.
